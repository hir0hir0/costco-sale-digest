# ブラックボックス評価セット（初見ユーザ視点）

> **使うタイミング**: 現時点は自分用フェーズのため、まだ不要。
> 一般公開に踏み切る直前と、公開後の月1チェックで使う。

**このフォルダは costco-sale-digest の外で使う。**リポジトリ内で実行すると、
Claude がコードを読んでしまい「初見ユーザには分からない」という判断が汚染される。

## 使い方（推奨: A）

**A. 通常のClaudeチャットで**
1. 新しいチャットを開く（リポジトリを開かない）
2. `tasks.md` とサイトのスクリーンショットを添付する
3. `.claude/agents/first-time-user.md` の本文（`---`より下）をそのまま貼り付けて指示する

**B. 別リポジトリで**
1. `costco-blackbox` のような別リポジトリを作り、このフォルダの中身を置く
2. そのリポジトリでセッションを開き `first-time-user エージェントで tasks.md の評価を実行して` と言う

## 見せるもの

- **実際に触らせる場合**（推奨）: 公開URLまたはローカル起動URLを渡す。
- **スクショの場合**: 最低5枚 — トップ / 一覧 / 商品詳細（価格履歴グラフ）/ 検索結果 / スマホ幅。
  ファイル名は `01-top.png` のように順番が分かる形にする。

## 禁止事項（守らないと意味がない）

- サイトの設計意図・技術構成・苦労した点を**説明しない**
- 「ここを見てほしい」と誘導**しない**
- **データの出所を教えない**（メルマガとレシートの2系統があることも言わない）。
  それが画面から分かるかどうかが、このサイト最大の争点である
- 用語を教えない（「値引き」「クーポン」の区別も、分からないなら分からないまま報告させる）

## 結果の扱い

出力された `findings.md` を costco-sale-digest の `docs/review/reports/` にコピーし、
必要なら review-critic に検証させる。
