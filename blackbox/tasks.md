# 初見ユーザ評価タスク

あなたはこのサイトを今日初めて見た人です。作った人の意図は知りません。

## ルール
- **推測で補完しない。** 画面に書いていないことは「分からなかった」と書く。
- 各タスクで、**詰まった瞬間**と**そのとき何を探したか**を必ず記録する。
- 完了できなかったタスクは、無理に完了させず「失敗」として報告する。それが最も価値のある情報。

## 事前印象（サイトを開いて最初の3秒）
- Q0-1. このサイトは何をするサイトだと思ったか
- Q0-2. その根拠になった画面上の要素は何か
- Q0-3. この価格情報はどこから来ていると思ったか。信用できると感じたか

## タスク

| ID | やること | 記録すること |
|----|---------|-------------|
| T1 | 今週の値引き商品を一覧する | クリック数 / 迷った箇所 |
| T2 | 適当な商品を1つ選び、「これはいつもより安いのか」を判断する | 判断できたか / 何を根拠にしたか |
| T3 | ある商品の過去の価格推移を調べる | 到達できたか / 期間はどれくらい遡れたか |
| T4 | 「今が買い時か（過去最安に近いか）」を判断する | 判断できたか |
| T5 | クーポン対象の商品だけを見る | 絞り込めたか / 割引の種類の違いが分かったか |
| T6 | 商品名で検索する（わざと表記を変える。カタカナ↔英字、部分入力） | ヒットしたか |
| T7 | このデータがいつ時点のものか調べる | 分かったか / どこに書いてあったか |
| **T9** | ある価格が「お店が告知した値段」なのか「誰かが実際に払った値段」なのか調べる | **区別が付いたか / どこで気づいたか / そもそも2種類あると気づいたか** |
| T8 | スマホ幅（375px）で T1→T2 をやり直す | 横スクロールの有無 / 読めない要素 |

> T9 は特に重要。**もし「2種類の価格がある」ことに最後まで気づかなかったなら、それをそのまま報告すること。**
> 気づかなかったこと自体が最も価値のある発見です。

## 最後に必ず答えること
1. **このサイトをまた使うと思うか。理由を1文で。**
2. 一番混乱した画面はどれか
3. 「これが無いなら使わない」と感じた不足は何か
4. 逆に、無くても困らないと感じた要素はどれか
5. 似た情報を得るために、いま自分なら代わりに何をするか（例: 公式アプリ、SNS、店頭で見る）
6. このサイトに載っている情報を、どの程度信用したか（1〜5）。その理由
